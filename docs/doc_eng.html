1. Common engine description

GLVM engine based on simple entity component system (ECS) that using sparse arrays provided cache friendly data. ECS gives opportunity to easily add or remove new systems that working with components. Common working with GLVM based on creating of three super objects. One of them - is instance of engine itself, and we also need EntityManager and ComponentManager for using ECS system. Most of common GLVM object is located in special namespaces.

2. Common GLVM functions

  • Create engine instance This is main super object of GLVM engine. Actualy its engine itself.
GLVM::core::Engine* GLVM = GLVM::core::Engine::GetInstance();
  • Create entity manager instance With this super object you can manage entities.
GLVM::ecs::EntityManager* EntityManager = GLVM::ecs::EntityManager::GetInstance();
  • Create component manager instance With this super object you can manage components.
GLVM::ecs::ComponentManager* ComponentManager  = GLVM::ecs::ComponentManager::GetInstance();
  • Create entity All entities in GLVM exposed just as an integer number. When you call function CreateEntity you have to catch return value because its marked with [discard].
Entity uiPlayer = EntityManager->CreateEntity();
  • Create component When you create entity you can link components to it with call to a function CreateComponent<…place your list of components here…>(entity). This function is method of ComponentManager and it supports any number of components as template variadic parameters. Set all components you need in <> and pass target entity in ().
GLVM::ecs::ComponentManager->CreateComponent<GLVM::ecs::components::mesh,
                                             GLVM::ecs::components::transform,
                                             GLVM::ecs::components::rigidBody>(entity);
  • Get component After you link components to any entity you can access each single component to change it for your purposes. This can be achieved with a call to a GetComponent function. This function is method of ComponentManager. When you call it, pass target entity to () and pass target component that linked to target entity to <>.
*GLVM::ecs::ComponentManager->GetComponent<cm::transform>(uiPlayer) = {
    .tPosition = { 5.7f, 10.0f, 7.0f }, .fScale = 0.1f };
